# Synthetic Data Evaluation

A Python project demonstrating how to generate synthetic data and evaluate its statistical similarity to real data.

## Overview
This script generates a "real" dataset using a normal distribution, creates a synthetic dataset with matching statistical properties, and uses the Kolmogorov-Smirnov test to evaluate if the distributions are statistically similar.

## Key Concepts
- **Synthetic Data:** Artificial data generated to mimic real-world data.
- **KS Test:** A statistical test to compare two distributions.
- **Privacy-Utility Trade-off:** Understanding how synthetic data can be used for privacy-preserving research.
